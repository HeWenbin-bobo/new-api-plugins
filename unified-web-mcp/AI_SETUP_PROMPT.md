# 用 AI 配置本包：推荐提示词

把下面这段发给你的 AI 助手（Claude Code / Codex / Cursor 等均可）。**先解压，改成你的真实路径和客户端名，再发送。**

---

## 完整版（推荐）

```text
我拿到了一个本地 MCP 网关的压缩包，已经解压到：<解压后的 unified-web-mcp 目录的绝对路径>

请帮我安装并注册到 <客户端名称，例如 Claude Code / WorkBuddy / Codex>。

必须遵守：
1. 先完整阅读该目录下的 INSTALL_NOTICE.md，以它为准。不要自己猜测 Node 版本、启动命令、配置字段或工具名。
2. 绝对不要把我提供的 Key 打印到终端、写进日志、写进 README 或提交到任何仓库。Key 只允许写进 config.json。
3. 修改客户端 MCP 配置前，先备份原文件，并且只做「合并」，不要覆盖我已有的其他 MCP 服务器。
4. 缺少信息就问我，不要编造 Key、路径或客户端字段名。
5. 装完按 INSTALL_NOTICE.md 的自检步骤验证，最后如实告诉我：哪些步骤你实际跑了、结果是什么、哪些没有验证。
6. 如果环境不满足（例如 Node 低于 24、没有 npm），停下来告诉我，不要试图降级或绕过。

我的情况：
- 操作系统：<Windows 11 / macOS / Linux>
- 客户端版本：<如有>
- 我有这些 Key（没有的直接写"没有"）：
  - MiniMax：
  - DeepSeek：
  - AnySearch（可选）：
  - Jina（可选）：
- 我是否要启用 SearXNG 自建实例：<是/否>

请开始。每完成一个阶段就简短汇报一次进度。
```

## 精简版（只想让它自己跑）

```text
解压后的项目在 <绝对路径>。先读 INSTALL_NOTICE.md，按里面的步骤安装并注册到 <客户端>。
只填我提供的 Key，不要打印 Key，不要覆盖我已有的 MCP 配置，装完跑自检并如实报告验证结果。
我的 Key：MiniMax=<有/无>，DeepSeek=<有/无>，其他=<有/无>
```

---

## 为什么这样写

| 提示词里的约束 | 防的是什么 |
|---|---|
| 「先读 INSTALL_NOTICE.md」 | AI 凭常识编出错误的启动命令或字段名 |
| 「不要打印 Key」 | Key 进入终端历史、日志、聊天记录 |
| 「只做合并」 | 覆盖掉你已有的 MCP 服务器配置 |
| 「缺信息就问我」 | 编造假的 Key 或路径，装出一个跑不通的环境 |
| 「如实报告验证结果」 | 把「装完了」当成「验证通过」 |
| 「环境不满足就停」 | 强行降级 Node 或在缺依赖时反复重试 |

---

## 你（作为接收方）需要自己提供的三件事

1. **解压路径** — 必须是绝对路径，AI 才能定位。
2. **客户端名称** — 不同客户端的注册方式完全不同。
3. **Key 的归属** — 只说你有哪些，**不要把 Key 明文贴进提示词**；等 AI 让你填时再写进 `config.json`。

没有 Key 也能装：`free` 渠道无需任何凭据，装完即可用。付费渠道是「填了才启用」，不会因为缺 Key 出错。
